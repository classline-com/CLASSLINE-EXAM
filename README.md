# CLASSLINE EXAM

سامانه آزمون تستی آنلاین کلاس‌لاین، با رابط کاربری مناسب Telegram Mini App.

## وضعیت فعلی
- رابط اولیه فارسی و راست‌چین در `index.html`
- ساختار اولیه دیتابیس Supabase در `supabase/schema.sql`
- این نسخه هنوز به بات تلگرام یا دیتابیس متصل نیست و داده واقعی ثبت نمی‌کند.

## معماری هدف
- Frontend: HTML/CSS/JavaScript روی GitHub Pages
- Database: Supabase PostgreSQL (پلن رایگان برای شروع)
- Backend: Supabase Edge Functions
- Telegram: Telegram Mini Apps و Bot API

## امنیت الزامی
1. توکن بات تلگرام و کلید `service_role` هرگز نباید در فایل‌های frontend یا مخزن GitHub قرار بگیرند.
2. سرور باید امضای `Telegram.WebApp.initData` را اعتبارسنجی کند.
3. پاسخ صحیح سؤال‌ها در جدول خصوصی نگهداری می‌شود و نباید به مرورگر دانش‌آموز ارسال شود.
4. دانش‌آموز فقط باید پاسخ‌نامه خودش را ببیند؛ دسترسی مدیر باید در سمت سرور کنترل شود.
5. رتبه و تراز فقط پس از زمان انتشار تنظیم‌شده برای آزمون قابل مشاهده باشد.

## مراحل راه‌اندازی
1. ایجاد پروژه Supabase و اجرای فایل `supabase/schema.sql` در SQL Editor.
2. ساخت Edge Functions برای اعتبارسنجی تلگرام، دریافت آزمون، ذخیره پاسخ، ثبت نهایی و انتشار نتایج.
3. افزودن تنظیمات محرمانه به Secrets بخش Supabase؛ نه به GitHub.
4. فعال‌کردن GitHub Pages برای شاخه `main` و پوشه ریشه.
5. تنظیم آدرس HTTPS مینی‌اپ در BotFather و اتصال دکمه منوی بات.

## محاسبات
- درصد هر درس بر اساس تعداد صحیح، غلط، نزده و قانون نمره منفی همان آزمون محاسبه می‌شود.
- ضرایب درس‌ها در محاسبه نمره کل اعمال می‌شوند.
- روش تراز باید پیش از اولین آزمون تعیین و مستند شود؛ تراز بدون داده آماری واقعی قابل محاسبه معتبر نیست.

## Development
فعلاً فایل `index.html` فقط پوسته نمایشی است. تا زمان تکمیل Backend و امنیت، برای آزمون واقعی استفاده نشود.
